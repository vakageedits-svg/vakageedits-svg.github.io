Responsabile e finalità

Minuto Strano Auto è gestita dal proprietario del canale YouTube Minuto Strano, contattabile a vakageedits@gmail.com. È uno strumento ad uso personale, non un servizio per utenti terzi. I dati Google/YouTube vengono usati esclusivamente per gestire il canale autorizzato.

Dati utilizzati

L’app utilizza l’identificativo del canale autorizzato, l’elenco e gli identificativi dei suoi video, titoli, descrizioni, tag, impostazioni di pubblico e visibilità, date di pubblicazione programmata e stato di elaborazione. Gestisce i file video da caricare e conserva un registro operativo di slot, upload ed errori per evitare duplicazioni.

L’accesso avviene tramite OAuth Google, con autorizzazioni YouTube per caricamento, lettura e gestione dei video (youtube.upload, youtube.readonly e youtube.force-ssl). L’app non richiede né conserva la password Google e non accede a Gmail, contatti o Google Drive.

Utilizzo e condivisione

I dati non vengono venduti, ceduti per pubblicità o condivisi con terzi per finalità autonome. Sono trattati soltanto dal proprietario e dai fornitori tecnici necessari: Google/YouTube per le operazioni sul canale e GitHub per l’esecuzione privata della pipeline e la conservazione del suo stato. Non vengono inviati ai servizi di generazione testo, voce o ricerca stock token OAuth o dati privati del canale.

I video e i metadata destinati alla pubblicazione diventano visibili su YouTube soltanto secondo le impostazioni scelte dal proprietario. I dati ottenuti dalle API Google non vengono utilizzati per addestrare modelli AI generalisti.

Conservazione e sicurezza

I token OAuth sono conservati nel dispositivo del proprietario in file con accesso limitato e, per le esecuzioni cloud, nei GitHub Actions Secrets cifrati. Durante l’esecuzione sono disponibili al processo autorizzato per il tempo necessario. Non vengono inseriti nel codice, nei commit, nei report o nelle pagine pubbliche.

Il registro operativo è conservato in un repository GitHub privato; i file di lavoro possono restare sul dispositivo del proprietario e negli artifact privati delle esecuzioni. I token sono mantenuti finché necessari all’autorizzazione, i dati operativi finché utili alla gestione e all’anti-duplicazione. Il proprietario può eliminarli; eventuali copie storiche e backup devono essere gestiti separatamente. Nessuna conservazione locale implica una garanzia di validità indefinita dei token.

Revoca dell’accesso e cancellazione

Puoi revocare l’accesso dalla pagina Collegamenti del tuo Account Google, selezionando Minuto Strano Auto e rimuovendo il collegamento. La revoca interrompe le future operazioni autorizzate ma non elimina automaticamente video già presenti su YouTube o registri già salvati.

Per chiedere la cancellazione dei token e dei dati conservati dall’app, o per domande sui dati, scrivi a vakageedits@gmail.com. I video già caricati possono essere gestiti o eliminati dal proprietario tramite YouTube Studio.

Sito informativo

Questo sito non include moduli, pubblicità, strumenti di analisi o cookie applicativi. È ospitato su GitHub Pages; GitHub può trattare dati tecnici, incluso l’indirizzo IP, per erogazione e sicurezza, secondo la Privacy di GitHub.

Regole Google

L’utilizzo e il trasferimento delle informazioni ricevute dalle API Google rispettano la Google API Services User Data Policy, inclusi i requisiti Limited Use. Le modifiche alle pratiche descritte saranno riportate in questa pagina.
